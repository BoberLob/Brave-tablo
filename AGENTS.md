\## Git workflow



\- Work directly on the main branch.

\- Do not create feature branches.

\- Do not create pull requests.

\- Commit changes locally after successful tests.

\- Push commits directly to origin/main.

\- Never use force push.

\- If direct push is rejected, stop and report the reason.



for backend, use uv for dependency management. a few useful commands: uv sync, uv add, uv run python
